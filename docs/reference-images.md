# 参考画像をレイヤーに取り込む

MCPaint 0.3.0では、PNG/JPG/JPEG/WebPを独立したレイヤーとして読み込めます。参考画像を下に置き、別のレイヤーに線を引く使い方に対応します。

## 画面から操作する

1. 線を引く描画レイヤーを選びます。必要なら、レイヤー一覧の［＋］で追加します。
2. ［画像］→［参考画像を背面に読み込む…］を選び、画像ファイルを開きます。
3. 参考画像は最背面へ追加されます。縦横比を保ってキャンバスに収まり、中央に配置されます。不透明度は50%、ロックは有効です。線を引くレイヤーの選択は変わりません。
4. 選択中の描画レイヤーに線を引きます。
5. 完成したら、レイヤー一覧で参考画像のチェックを外します。参考画像が非表示になり、描いた線は残ります。
6. `.mcpaint`と完成PNGを保存します。

参考画像の濃さを変える場合は、そのレイヤーを選んで［レイヤーの不透明度］を調整します。描画を続けるときは、線を引くレイヤーを選び直してください。参考画像を変形する場合は、ロックを外してから［画像］→［選択範囲・レイヤーを変形］を使います。

［画像を新しいレイヤーに読み込む…］では、選択レイヤーの上に、不透明度100%・ロックなしの画像レイヤーを追加します。その画像レイヤーが選択されます。［画像を選択レイヤーへ貼り付ける…］では、選択中の描画レイヤーへ画像を貼り付けます。

## MCPから操作する

`import_image_layer`を呼びます。パスはMCPaintが動くWindows PC内のファイルを指定してください。

```json
{"path":"C:\\Pictures\\reference.jpg","name":"お手本"}
```

結果にはPNGと状態に加えて、追加したレイヤーの`imported_layer_id`が入ります。標準設定は背面・中央・キャンバスに収まるサイズ・不透明度50%・ロック付きです。現在の描画レイヤーは選択されたままです。

返されたPNGを確認し、`draw_stroke`で線を引きます。完成したら、`update_layer`で参考画像を非表示にします。`layer_id`には、取り込み時に返されたIDを入れてください。

```json
{"layer_id":"取り込み時に返されたID","visible":false}
```

濃さを30%にするには、同じ`layer_id`と`opacity=0.3`を`update_layer`へ渡します。取り込み時の主な設定は次のとおりです。

| 設定 | 意味 |
|---|---|
| `placement="back"` | フォルダーの外の最背面へ追加する |
| `placement="above"` | 選択レイヤーの上へ追加する。フォルダーを選択中なら、その中へ追加する |
| `fit="contain"` | 縦横比を保ち、キャンバスに収めて中央へ配置する |
| `fit="original"` | 元のピクセル数で中央へ配置する。キャンバス外の部分は切れる |
| `opacity` | 0〜1で不透明度を指定する |
| `locked` | 描き込みを防ぐロックを指定する |
| `select_imported` | 追加した画像レイヤーを選択するか指定する |

画像の取り込みは現在の選択範囲に制限されません。PNGの透過を保持し、JPEGの向き情報を反映します。取り込みは1回の操作として取り消し・やり直しできます。

## 保存と対象範囲

元画像は16MB以下、縦横それぞれ4096px以下が対象です。参考画像も64レイヤーの上限に含まれます。

画像データをプロジェクト内に保存するので、元ファイルを移動・削除しても開き直せます。非表示・不透明度・ロックの設定も保存します。0.1.0/0.2.0のプロジェクトを読み込めます。0.3.0で保存したプロジェクトは0.3.0以降で開いてください。

完成PNGには、その時点で表示中のレイヤーが入ります。タイムラプスには、参考画像が表示されていた途中の工程も入ります。
