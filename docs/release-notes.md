MCPaint 0.3.0。PNG/JPGを参考画像レイヤーとして取り込み、その上に線を引く機能を追加しました。

- ［画像］→［参考画像を背面に読み込む…］で、独立した参考画像レイヤーを追加
- 背面・不透明度50%・ロック付きの初期設定。描画レイヤーの選択は保持
- 縦横比を保って中央に配置。PNGの透過とJPEGの向き情報に対応
- レイヤー一覧のチェックを外すと、参考画像を非表示にして完成PNGを出力可能
- 通常の画像レイヤーとして取り込む操作と、選択レイヤーへ貼り付ける操作も用意
- MCPの`import_image_layer`から、取り込み・配置・不透明度・ロック・選択を指定可能。追加したID、状態、PNGを返す
- 画像データをプロジェクト内に保存。元ファイルの削除後も復元・再生可能
- 取り消し・やり直し、保存、タイムラプスに対応。0.1.0/0.2.0のプロジェクトを読み込み可能

34個すべての公開MCPツールを実際のstdio通信で呼び出すテストに、参考画像から線を描き、画像を非表示にして保存する工程を追加しました。配布EXEでもPNG/JPGの取り込みとMCP操作を検査しています。

`MCPaint-0.3.0-windows-x64.zip`全体を展開し、以前のMCPaintを終了してから`MCPaint.exe`を起動してください。Windows 10/11 64bitが対象です。PythonやFFmpegのインストールは不要です。`_internal`フォルダーを保持してください。

Codexには同じフォルダーの`MCPaint-MCP.exe`を登録します。設定手順は`docs/mcp-setup.md`、参考画像の操作とMCPの例は`docs/reference-images.md`にあります。

0.3.0で保存したプロジェクトは0.3.0以降で開いてください。タイムラプスには、参考画像が表示されていた途中の工程も入ります。元画像は16MB以下・縦横4096px以下が対象です。EXEは未署名です。
