MCPaint 0.2.0。Windows 10/11 64bit向けの、ローカルMCP対応ペイントアプリです。CLIP STUDIOの公式作画解説を参照し、下塗り・陰影・仕上げの工程に必要な操作を追加しました。

- 9種類のブラシ、筆圧、手ブレ補正、図形・ベジェ曲線
- レイヤーフォルダー、複製・統合、クリッピング、透明ピクセルロック、マスク、13合成モード
- 長方形・楕円・投げ縄・自動選択、反転・追加・削除・拡張・縮小・境界ぼかし
- 別レイヤー参照の塗りつぶし、すきま閉じ、領域拡張、囲って閉領域を塗る操作
- グラデーション、スポイト、画像読み込み、変形・メッシュ変形、反転・回転表示
- 色調補正・トーンカーブ・グラデーションマップの非破壊補正レイヤー
- 各MCP操作でPNG画像と座標情報を返す、画面確認を伴う描画
- 制作過程の自動記録、編集プロジェクト保存、自動保存・復元
- 完成PNG、制作タイムラプスMP4/GIF出力

33個すべてのMCPツールについて、実際のstdio接続から画像を受け取り、下塗り・陰影・仕上げ・保存・MP4出力を通す結合テストを追加しました。0.1.0のプロジェクトを読み込めます。

`MCPaint-0.2.0-windows-x64.zip` をダウンロードし、全体を展開して `MCPaint.exe` を起動してください。Pythonのインストールは不要です。以前のアプリを終了してから起動してください。

Codexへ接続する際は、同じフォルダーの `MCPaint-MCP.exe` をstdio MCPサーバーとして登録してください。詳しい手順は同梱の `docs/mcp-setup.md` にあります。

`_internal`フォルダーを保持してください。EXEは未署名です。Windowsビルド内でテストと配布EXEの起動検査を行ってから公開しています。

参照解説との照合、MCP操作、再現範囲は `docs/illustration-workflow.md` を確認してください。クリスタのブラシ・専用ファイル形式・全機能の互換版ではありません。
