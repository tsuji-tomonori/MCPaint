## AIが作画する基本手順

1. `screenshot(grid=true)`で画面と座標、レイヤーを確認します。
2. ラフと線画を別のレイヤーに描きます。曲線は`draw_stroke`の点列か、`draw_shape(kind="bezier")`の4点で指定します。
3. 線画の下に下塗りレイヤーを置き、`fill_area(reference="layer", reference_layer_id=線画ID)`で塗り分けます。必要ならすきま閉じと領域拡張を指定します。
4. シルエットを作る場合は、線画の外側を自動選択し、反転して下塗りを塗ります。選択範囲の画像で範囲を確認します。
5. ベースのすぐ上に塗りフォルダーを置き、クリッピングを有効にします。線画はその上に置きます。フォルダー内に部位や色ごとのレイヤーを追加します。
6. 影には乗算、光にはスクリーン・加算を使います。操作後の画像を確認しながら、不透明度や色を調整します。
7. 柔らかく消したい部分はマスクに描きます。`screenshot(scope="mask")`でマスクの状態を確認できます。
8. 仕上げには補正レイヤーのカラーバランス、トーンカーブ、グラデーションマップを使います。元のピクセルは変わらず、あとから補正を変えられます。
9. `.mcpaint`、PNG、MP4/GIFを保存します。0.1.0のプロジェクトも読み込めます。

元のキャンバスのピクセルで座標を指定します。表示の反転・回転・拡大はMCPの座標を変えません。選択範囲、マスク、クリッピングは別々の制約です。選択範囲は編集を制限し、マスクとクリッピングは表示を制限します。

参考画像を背面に置いて描く場合は、[参考画像の取り込み手順](reference-images.md)を参照してください。0.3.0から、画像を独立したレイヤーとして追加できます。

## 補正設定の例

```json
{"kind":"tone_curve","points":[[0,0],[64,52],[128,140],[255,255]]}
```

```json
{"kind":"gradient_map","stops":[[0,"#3e355e"],[0.5,"#dbafa1"],[1,"#fff3d4"]]}
```

同じ設定を`apply_filter`に渡すと、選択レイヤーのピクセルへ適用します。`add_adjustment_layer`に渡すと、下のレイヤーに対する非破壊の補正になります。

## 再現できる範囲

- 作画工程に必要な操作を追加したもので、CLIP STUDIO PAINTのファイル形式、ブラシ資産、全機能の互換実装ではありません。
- 水彩・飛沫・色混ぜはMCPaint独自の描画処理です。クリスタと同一の筆跡や絵の完成品質は保証しません。
- メッシュは凸四角形のセルごとの射影変換です。クリスタの滑らかなメッシュ補間とは異なります。
- トーンカーブは指定点間の直線補間です。GUIでは中間点1個、MCPでは最大32点を指定できます。
- フォルダーは通常のグループ合成です。パススルー合成、ベクターレイヤー、3Dモデル、PSD/CLIP入出力、専用素材・ブラシ形式の読み込みは含みません。
- レイヤー統合は同じフォルダーの、表示中・通常合成・クリッピングなしの描画レイヤー2枚が対象です。
- AIからの操作経路と工程の再現をテストしています。AIが任意の題材を人間のプロと同じ品質で描けるという判定ではありません。
